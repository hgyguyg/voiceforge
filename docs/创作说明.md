# 创作说明（≤300 字）

**为什么选这个**

想做一个只有 AI 才做得到、以前做不了的东西：造一副不存在的声音。真人录音要有真人，克隆要有样本——那「七十岁、抽了四十年烟、说话像在赌气」的老太太，上哪儿录去？百炼把这事反过来：不给样本，给一句话。

**看点**

① 同一句描述每造一次都是另一副嗓子，「重抽」本身就是玩法；② 抽到就锁成一张带编号、真波形、二维码的声音卡，别人扫码能让这副声音念他自己想说的话。声音从「功能」变成「角色」。

**AI 工具**

DeepSeek（DSH 编程 Agent）写全部代码、调试与文案；阿里云百炼 CosyVoice 声音设计 + 语音合成是产品内核。

**踩的坑**

合成端点误用多模态端点，报 `url error` 卡一整晚；文档里的新域名解析不了，退回旧域名才通；面板隐藏时画布算成 0×0，波形永远空白。

**标题与平台**

《我让 AI 凭一句话，造出了 47 副不存在的声音》，小红书首发配动图，公众号同步长文。
